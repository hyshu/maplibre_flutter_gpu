# Kenney CC0 model data

`lib/gpu/kenney_mesh_data.dart` contains position, normal, and index data
converted from these Kenney models:

- `sedan.glb` from [Car Kit](https://kenney.nl/assets/car-kit)
- `low-detail-building-a.glb` from
  [City Kit (Commercial)](https://kenney.nl/assets/city-kit-commercial)

Both packs are published under
[CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).
Colors, UV coordinates, materials, textures, and original GLB files are not
bundled in the app.
